# 提交规格（以平台页面为准）

> 本文回答三个问题：**交什么包、什么格式、要哪些东西**。
> 依据：平台 11.4 说明全文（`../expert-task-batch-20261109/SPEC-11.4.md`）+ 复核 Base 中真实附件的形态。
> 平台页面若与本文冲突，以页面为准；未确认项标 `TBC`。

## 1. 交什么：六类材料

| # | 材料 | 内容 | 槽位 |
|---|---|---|---|
| 1 | Prompt 与提示词附件 | 题面 + 输入材料 | `01_prompt_attachments/` |
| 2 | Ideal Steps | 专业人员的执行路径（操作/判断/异常/核验） | 文本字段 |
| 3 | Golden Response | 完整标准答案 + 标准交付/复核底稿 | `02_ideal_attachments/` |
| 4 | 专家 Rubric | 必需项+负向 5–12 条（复杂 15+），加分 ≤2，Gate ≤3 | 表格字段 |
| 5 | 豆包实际输出 | 原始文本 + 回答链接 + 反馈链接 + 生成附件 | `03_doubao_outputs/` |
| 6 | 评级与评价 | 难度/回答评级/运行时长/具体评价 | 文本字段 |

**三类附件槽位不能混、不能重复上传同一文件。**

## 2. 什么格式

| 类型 | 推荐格式 | 说明 |
|---|---|---|
| 表格数据 | **XLSX / CSV** | 不要只传截图；CSV 用 UTF-8 |
| 文档 | **DOCX / PDF** | 长 PDF 要说明用途与相关章节 |
| 图片 | PNG / JPG | 截图类证据 |
| 压缩包 | ZIP | 复核记录里实际出现 `task19_input.zip` 等，说明平台接受 zip；但网页端上传 zip 可能不稳，优先解包逐个传 |
| 单文件上限 | `TBC` | 旧口径：单件 ≤20 MB、≤11 个、合计 ≤2 GB；11.4 未重申 |
| 命名 | 唯一 + 前缀 | 如 `A01_valuation.xlsx`，避免同名覆盖 |

**禁止上传**：重复文件、完整数据库导出、无关整本报告、不可访问链接、加密文件、嵌套压缩包。

## 3. 要哪些字段

### 3.1 专家信息

平台昵称、飞书联系方式、真实岗位、资质说明；行业 / 二级 Skill / Skill 描述 / 对应岗位 / 三级 Skill 由平台适配给出，需确认归类准确。

### 3.2 能力选择

多选，只勾本题真实发生的动作；删掉某标签题目仍成立 → 不勾。

### 3.3 题面必须写清

任务目标、业务背景、输入范围、输出要求、使用限制、时间边界、单位口径、验收重点。
**不能写**：标准答案、关键结论、完整解题步骤、现成排除清单、可反推答案的校验信息。
**可以写**：规则参数、阈值、单位精度、口径定义。

### 3.4 豆包输出与版本确认

- 输出文本：原始、不润色。
- 回答链接：对话「…」→「复制分享链接」。
- 反馈链接：回答下方「…」→「反馈与举报」→「复制信息」取链接。
- 输出附件：模型实际产物。
- 版本确认：**豆包会员-工作-云电脑-豆包2.1pro-推理强度高**。
- 分享前确认已脱敏。

### 3.5 评级与评价

| 字段 | 取值 |
|---|---|
| 难度 | 低 / 中 / 高（看链路、信息复杂度、判断责任、验收复杂度；不看附件数/长度） |
| 回答评级 | 不达标 / 基本达标 / 优秀 |
| 运行时长 | 少于 40min / 40min 及以上 |
| 联网 | 否 / 是（是则写检索目标、来源范围、截止时间） |
| 评价 | 必须引用具体例子：完成度、事实/判断、遗漏与假设、可否复核使用、改进建议 |

## 4. 验收（决定结算）

| 轮次 | 检查 | 通过条件 |
|---|---|---|
| 一轮 | 完备性 / AI 率 / 高经济价值 | 关键输入齐全、GT 可判分、输入未泄答案；附件像真实业务而非现造；产物有下游使用者 |
| 二轮 | 难度硬门槛 | **机标 judge ≤50 分 且 单轮模型调用步数 ≥50 步**；两项同时满足 |

- 不达标可返修一次；返修合格正常结算，仍不合格不结算。
- 时长只是评级字段，**不是门槛**（复核记录中 22 分钟、48.6 分钟均因步数不足被关闭）。

## 5. 提交与返修动作

1. 领题后 **48 小时内**提交；超时自动释放。
2. 一轮返修：按公示备注修改 → **手动把状态改为「已返修」**。
3. 二轮结果分「合格 / 返修 / 待质检」；「合格」无需动作。
4. 平台点「已完成」后不可随意改；提交前走完 `05_submission/READINESS.md`。

```text
packs/<task-id>/
  01_public/task_prompt.md              → 材料 1 的题面字段
  01_public/data/                       → 材料 1 的提示词附件
  02_platform_fields/expert_rubric.csv  → 材料 4
  02_platform_fields/ideal_steps.md     → 材料 2
  02_platform_fields/rating.md          → 材料 6
  03_private_review/GT/                 → 材料 3（只上传到理想回复附件槽位）
  04_evidence/                          → 运行日志、judge、步数、C20
  05_submission/01_prompt_attachments/  → 输入材料
  05_submission/02_ideal_attachments/   → GT/底稿
  05_submission/03_doubao_outputs/      → 豆包产出
```
