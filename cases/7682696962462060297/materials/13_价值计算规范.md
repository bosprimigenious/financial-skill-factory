# 价值计算规范

## 1. 统一分析样本

利润桥和因果估计使用同一闭合样本：通过样本口径 S01-S08，且激活后 30 日观察窗在业务截止前结束。未激活记录的观察窗以有效报价后 `activation_window_days + tpv_window_days` 结束；结束日在业务截止之后时不进入闭合样本。漏斗统计仍保留这些记录。

有效激活数仅统计满足全部阶段顺序和时限、且未在激活前有效取消的记录。30 日交易量是每个机会在其观察窗内最终可见 `SETTLED` 金额与 `REFUND` 金额之和。

## 2. 贡献利润桥

对每个分群，令：

- `N`：闭合样本的机会数。
- `A`：闭合样本的有效激活数。
- `V`：闭合样本 30 日交易量合计。
- `r_i`：机会最终有效净费率。
- `c`：分群变动成本 bp。
- `k`：分群单次激活成本。
- `r0`、`p0`、`v0`：分群基准净费率、基准激活率、每个合格机会基准交易量。
- `CREDIT`：闭合样本关联贷项金额的绝对值合计。

按机会交易量加权计算实际净收入：

```text
actual_net_revenue = sum(V_i * r_i / 10000)
actual_contribution = actual_net_revenue - V*c/10000 - A*k - CREDIT
baseline_contribution = N*v0*(r0-c)/10000 - N*p0*k
price_effect = sum(V_i*(r_i-r0)/10000)
volume_effect = (V-N*v0)*(r0-c)/10000
activation_cost_effect = -(A-N*p0)*k
credit_effect = -CREDIT
gap = actual_contribution-baseline_contribution
reconciliation = gap-price_effect-volume_effect-activation_cost_effect-credit_effect
```

贷项只在其关联发票的机会属于闭合样本且贷项在双截止下可见时计入。交易退款已经包含在 `V` 中，不得再次作为贷项扣减。

## 3. 应收与 DSO

应收只使用 `INVOICE`、`CREDIT` 和 `07_收款流水.csv`：

```text
invoice_net = posted invoice amount + posted credit amount
open_ar_invoice = max(0, invoice_net - settled cash applied)
open_ar = sum(open_ar_invoice)
net_revenue_90d = invoices_90d + credits_90d
dso_days = open_ar / net_revenue_90d * 90
```

90 日窗口为 `[business_cutoff-89 days, business_cutoff]`，按有效日期判断。`cash_applied` 输出全部可见已结算回款，不限于 90 日发票；`overdue_ar` 是业务截止时账龄严格大于该机会最终报价账期的未收金额。`net_revenue_90d <= 0` 时 DSO 不可用并产生 `MISSING_REQUIRED_INPUT`。原始 `invoice_net < settled cash` 时按零计 DSO，但记录 `NEGATIVE_AR`。

## 4. 下一周期预测

对一个分群的候选 `d_fee` 与 `d_term`：

```text
r1 = r0 + d_fee
t1 = t0 + d_term
q = ln(r1/r0)
u = d_term/30
predicted_conversion = clip(p0 + b_ap*q + b_at*u, 0, 1)
predicted_monthly_tpv = leads*v0*exp(b_vp*q + b_vt*u)
candidate_annual_contribution = 12*(predicted_monthly_tpv*(r1-c)/10000 - leads*predicted_conversion*k)
baseline_annual_contribution = 12*(leads*v0*(r0-c)/10000 - leads*p0*k)
annual_contribution_delta = candidate_annual_contribution-baseline_annual_contribution
annual_fee_revenue = 12*predicted_monthly_tpv*r1/10000
cash_release = annual_fee_revenue*(-d_term)/365
```

`b_ap`、`b_at` 来自 activation 的价格与账期系数；`b_vp`、`b_vt` 来自 log_tpv 的价格与账期系数。

下行情形取四个系数各自区间端点的全部 16 种组合，逐一代入同一公式；`downside_contribution_delta` 是 16 个贡献利润差额的最小值。零变化候选的点估计、下行情形和现金释放均强制为 0，避免浮点噪声。

## 5. 可行性与选择

按以下顺序为每个候选确定首个失败原因：

1. 分群因果状态不是 `IDENTIFIED`：`CAUSAL_INSUFFICIENT`；零变化候选除外。
2. `r1 <= c`：`NONPOSITIVE_UNIT_MARGIN`。
3. 账期越过分群上下界：`TERM_OUT_OF_RANGE`。
4. `predicted_conversion < p0-max_conversion_decline_pp`：`CONVERSION_GUARDRAIL`。
5. `annual_contribution_delta < 0`：`POINT_VALUE_NEGATIVE`。
6. `downside_contribution_delta < 0`：`DOWNSIDE_VALUE_NEGATIVE`。

无失败原因时 `feasible=true`。在可行候选中按控制表“选择顺序”决定唯一动作。零变化始终可行；若只有零变化可行，`action=HOLD`，否则 `action=CHANGE`。

## 6. 现金释放

`working_capital.csv` 的 `annual_fee_revenue` 和 `cash_release` 取入选候选的预测值。费率变化本身不形成现金释放；正账期变化增加占用，因此现金释放为负。不得把商户交易结算余额、交易退款或尚未发生的利润改善计入现金释放。

## 7. 行动改善

每项行动按登记表日期、分群与臂条件，从通过 S01-S08 的机会中形成处理组和对照组；不要求 30 日闭合的行可计样本数，但转化、贡献和 DSO 只使用各自已闭合或可计量的记录。

```text
observed_fee_delta_bps = mean(net_rate_treatment)-mean(net_rate_control)
conversion_delta = activation_rate_treatment-activation_rate_control
contribution_per_eligible_delta = contribution_treatment/n_treatment - contribution_control/n_control
dso_delta = dso_treatment-dso_control
```

状态顺序如下：

1. 任一臂样本小于 `min_each_arm`：`INSUFFICIENT_SAMPLE`。
2. 对应分群因果状态不足：`HOLD_EVIDENCE`。
3. 观察到的主动作幅度与登记目标同号且绝对值达到目标的 80%，同时主指标达到登记目标：`ACHIEVED`。
4. 主指标方向改善但未达到目标：`ADJUST`。
5. 其他情况：`STOP`。

主指标由 `metric` 指定。`CONTRIBUTION_PER_ELIGIBLE` 的改善方向为正；`DSO` 的改善方向为负。目标为零的非主指标不参与状态判断。

## 8. 整体结论

利润桥绝对勾稽差超过 0.01 元产生 `RECONCILIATION_FAIL`。任一数据阻断码存在时整体为 `HOLD_DATA`；否则，只要至少一个分群动作为 `CHANGE` 且全部入选动作可行，整体为 `PROCEED`；全部为 `HOLD` 时整体为 `HOLD_EVIDENCE`。
