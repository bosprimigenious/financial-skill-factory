# 交付接口

## Python 接口

`evaluate_bundle(bundle_dir, cutoff)` 读取本目录内的 `.jsonl` 与时钟 CSV，返回组合、限额检查、发布组和摘要。

`replay_incremental(state, records, cutoff)` 接收字典记录序列，返回可 JSON 序列化的新状态。其 `result` 必须与相同原始记录、相同截止时点的一次性运行一致。保存过较晚截止结果的状态仍须支持查询更早截止。

## 返回结构

```json
{
  "cutoff": "RFC3339",
  "portfolios": [
    {
      "portfolio_id": "P1",
      "release_group_id": "G1",
      "status": "released|blocked|indeterminate",
      "var": "0.000000|null",
      "expected_loss": "0.000000|null",
      "worst_stress_id": "S1|null",
      "worst_stress_loss": "0.000000|null",
      "top_controller_id": "I1|null",
      "concentration_share": "0.000000|null",
      "codes": ["..."],
      "evidence": ["event_id"]
    }
  ],
  "limit_checks": [
    {
      "scope_id": "P1 or G1",
      "limit_id": "L1",
      "metric": "var|expected_loss|stress_loss|concentration",
      "value": "0.000000|null",
      "threshold": "0.000000|null",
      "utilization": "0.000000|INF|null",
      "status": "ok|waived|breach|indeterminate",
      "evidence": ["event_id"]
    }
  ],
  "release_groups": [
    {
      "release_group_id": "G1",
      "status": "released|blocked|indeterminate",
      "codes": ["..."],
      "evidence": ["event_id"]
    }
  ],
  "digest": "lowercase sha256"
}
```

数组分别按 `portfolio_id`、`(scope_id, limit_id)` 和 `release_group_id` 排序。代码与证据数组按字典序排列并去重。金额、比率和数量均以六位小数字符串输出，无法确定时为 JSON `null`。

`digest` 在移除自身字段后，对 UTF-8、键排序、紧凑 JSON 计算小写 SHA-256。只允许 Python 标准库；时间必须带时区，数值必须使用 `decimal.Decimal`。

增量状态必须保留足以在任意更早截止时点完整重放的原始记录。相同 `event_id` 同正文幂等；不同正文不得覆盖。
