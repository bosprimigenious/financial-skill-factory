# 附件5　协同价值测算参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 企业所得税率 | 15% | 双方均为高新技术企业；协同收益与整合成本均按此税率处理 |
| 加权平均资本成本 WACC | 9.0% | 以买方资本结构与行业风险确定，用于协同现金流折现 |
| 永续期长期增速 g | 2.0% | 明确预测期之后协同的长期增长假设 |
| 明确预测期 | 2026—2028 年 | 协同按 3 年爬坡，2028 年达稳态 |
| 永续处理 | 2029 年起 | 2028 年末按戈登增长模型确认终值 |
| 折现基准 | 2025 年末 | 年度现金流按年末折现，2026 年为第 1 期 |
| 整合成本税务处理 | 税前可抵扣、当年全额抵扣 | 按 15% 税率折算税后整合成本；抵扣时滞（待核） |
| 金额单位 | 亿元 | 呈现保留两位小数；中间量精度见附件8 K-13 |

## 计算关系（供复核）
- 某项加权协同 = 复核后稳态真实协同 × 该类型实现率（概率）。
- 某年协同现金流 = 加权稳态协同（税后）× 该年释放比例。
- 某年净现金流 = 该年协同现金流 − 该年税后整合成本。
- 终值（2028 年末）= 2028 年税后稳态协同 ×（1+g）/（WACC−g）。
- 协同净 NPV = 各年净现金流及终值按 WACC 折现之和。
- "仅明确预测期口径"＝同一现金流但**不含终值**，用于稳健性对照。
