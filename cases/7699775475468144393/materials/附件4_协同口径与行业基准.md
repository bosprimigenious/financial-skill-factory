# 附件4　协同效应识别口径与行业基准（复核依据）

> 本附件提供协同的**定义口径与经验基准**，用于独立复核；不包含对本次各项协同的具体认定结论。

## 一、协同的基本口径
1. 协同效应仅指**因本次交易直接产生、在双方各自独立经营情形下不会发生**的增量现金流。
2. 下列项目**不属于协同**，应从测算中剔除：
   - 标的或买方**独立经营即可实现的改善**（含并购前已立项的降本、扩产计划）；
   - **行业自然增长**带来的收入；
   - 常规折旧抵税、原有税收优惠等**独立情形下同样存在**的项目。
3. **不得重复计算**：同一笔增量（如交叉销售带来的产能利用率提升）只能在收入端或成本端计一次。
4. 一次性**整合成本**应与可持续的**年度协同**分开列示，不得以年度协同净额掩盖整合投入。

## 二、三类协同的经验实现率（行业并购整合研究区间）
| 协同类型 | 典型实现率（可信度） | 说明 |
|---|---|---|
| 成本协同 | 65%–90% | 子类区间见附件8 K-03；职能/管理费用裁撤确定性最高 |
| 收入协同 | 30%–40% | 交叉销售、提价受客户与竞争影响，最不确定 |
| 财务协同 | 60%–80% | 融资成本下降较确定；税盾受可抵扣额度限制 |

## 三、爬坡（释放节奏）经验
- 多数横向并购协同分年释放约为：**第1年 25%–35%、第2年 60%–70%、第3年达到稳态**；
  整合初期受磨合影响，难以在首年过半。

## 四、整合成本与溢价基准
- 一次性整合成本通常约为**稳态年度协同（复核认定口径）的 0.7–1.2 倍**；
  裁员补偿、产线改造等多在交易后前两年集中发生。
- 可比横向产业并购的控制权溢价多在 **20%–35%** 区间。
- 税盾仅可就**可结转未弥补亏损等专项**在规定额度内确认；金额应以底稿中实际可结转额为上限，
  且区分"一次性"与"年度可持续"。

## 五、复核输出要求（口径层面）
- 逐项给出"认定 / 调减 / 剔除"及理由；
- 区分协同类型做**可信度（概率）加权**，并按经验节奏分年爬坡；
- 结果以**区间**表达为主；关键参数缺失、无法从底稿核实的，应标注"待核"，不得补造确定值。
