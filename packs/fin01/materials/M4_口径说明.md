# 口径说明（M4）

## S01 / S03 · SCFI

- 发布频率：周度，每周五发布当周指数；指数日为周五。
- 单位：综合指数为无量纲点位；分航线为 USD/TEU 或 USD/FEU。
- 综合指数由分航线加权得出，权重见下表（来源页面公开列示）。
- 分航线运价包含海运费及附加费（BAF/EBS/CAF/PSS/WRS/PCS/SCS 等）。

## S02 · 上证指数

- 频率：交易日日度；`released_at` 取当日 15:00（收盘后可得）。
- 单位：点位；收盘价为当日最后一笔成交的指数点位。

## 缺失值语义

- `UNKNOWN`：取值未知
- `NOT_OBSERVED`：当期未观测
- `NOT_PROVEN`：来源未给出可核验取值（**不得按 0 处理**）
