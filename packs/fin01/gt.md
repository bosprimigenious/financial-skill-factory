# 标准答案构建方法（GT）

**当前不写数值。** 数值必须由 M1–M4 独立推导，禁止用模型生成。

## 三层 GT

1. **Calculation GT**：由确定性脚本计算，输出
   - 每源覆盖率 = 实际观测实体数 / 目录声明的覆盖实体数
   - 每字段发布滞后 = median(released_at − ts)
   - 前视风险 = (released_at > 该字段在因子日的可用时点) 的比例
2. **Evidence GT**：每个结论挂到 `source_id + field + 行号`
3. **Narrative GT**：由上述数值拼装成验收意见，不自由发挥

## 判定规则（先冻结，再算）

| 情形 | 判定 |
|---|---|
| `released_at` 缺失或晚于观测日超过阈值 | 记为前视风险，不得入模 |
| `pit_flag=FALSE` 且无修订历史 | 拒绝入模 |
| 实体映射 `valid_to` 与观测日不重叠 | 该记录记为实体错配 |
| 缺失值标 `NOT_PROVEN` | 不得当 0，覆盖率高估 |
