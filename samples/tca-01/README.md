## 为什么材料是合成的

`测算交易成本` 需要逐笔成交回报（含到达价）——这类数据是券商的客户委托，**不可能公开获取**。
三条路里我只走可行的一条：

1. 真实授权成交回报：需要你提供（一张券商成交回报 + 费率协议即可）。
2. 公开数据替代：交易所不公开逐笔委托与到达价，做不出真 TCA。
3. 合成夹具：**当前采用**，只用于证明计算与判分正确，不作为"真实业务材料"提交。

合规上这条不能含糊：合成夹具在题面无任何"真实委托"暗示，`README` 与本表均标注，
且 `case_intake/authenticity_gate` 会以 `A5` 拒绝未标注的 synthetic 案例进入生成。

## 换真实材料要做的事（字段契约）

只替换 `materials/` 下三个 CSV，其余不动；`build_sample.py` 会重算 GT 并自检。

### `01_成交回报.csv`

| 字段 | 类型 | 说明 |
|---|---|---|
| `fill_id` | 文本 | 成交编号，唯一 |
| `order_id` | 文本 | 委托编号 |
| `symbol` | 文本 | 证券代码（与费率表一致） |
| `side` | 枚举 | `BUY` / `SELL` |
| `fill_time` | ISO8601 | 成交时间（含日期） |
| `fill_price` | 数值 | 成交价，元 |
| `fill_qty` | 整数 | 成交数量，股 |
| `order_qty` | 整数 | 委托数量，股（同一 order_id 各行须一致） |
| `arrival_price` | 数值 | 到达价（基准），元；须有来源说明 |

### `02_费率与基准.csv`

`symbol, tier_floor, tier_rate, min_fee, transfer_rate, exchange_fee_rate, stamp_duty_sell`
——同一证券多档用多行；`tier_floor` 为该档起点成交额（元）。

### `03_未成交订单.csv`

`order_id, symbol, side, order_qty, arrival_price` —— 当日完全无成交的委托。

**缺一项即不可判**：没有 `arrival_price` 就没有滑点，没有 `min_fee` 就无法判 R3，
没有未成交表就无法判 R6。这三类缺失在真实材料里很常见，属材料不合格而非题目简单。

## 计算口径（写死在代码里）

```
滑点      buy: fill - arrival ;  sell: arrival - fill        （正数 = 不利）
佣金      max(名义金额 × 档位费率, 最低收费)
过户费     名义金额 × transfer_rate          （双边）
经手费     名义金额 × exchange_fee_rate      （双边）
印花税     名义金额 × stamp_duty_sell        （仅卖出）
Cost BPS  10000 × (Σ滑点 + Σ显性费用) / Σ(到达价 × 成交数量)
未成交     单列，不计入 Cost BPS
```

当前夹具结果：5 笔成交 / 名义 707,780.00 / 滑点 170.00 / 显性费用 343.40 /
合计 513.40 / **7.2570 bps** / 未成交 5,100 股。

## 反例矩阵（这才是验收能力）

`tests/test_sample_tca.py` 的 13 项测试里，9 个是定向反例：

| 反例 | 注入的错误 | 必须命中的考点 |
|---|---|---|
| C1 | 卖出滑点符号取反 | R2 |
| C2 | 基准价被改动 100 元 | R2 |
| C3 | 佣金忽略最低收费 | R3 |
| C4 | 买入也计提印花税 | R4 |
| C5 | 订单成本率用简单平均 | R5 |
| C6 | 未成交数量被清零 | R6 |
| C7 | 成本率分母换成股数 | R7 |
| C8 | 缺口径声明 | R8 |
| C9 | 只交汇总、不交逐笔 | R1 |

外加 `TestCoverage` 断言 **8 条考点全部可达**——任何一条打不穿，测试就失败。
这条设计针对的是 V1 的老毛病：考点看起来齐全，实际只有几条真的能扣分。

## 下一步（要你定的一件事）

这个样板卡在材料上。两条路：

1. 你给一份**可授权的成交回报 + 费率协议**（脱敏即可），我把它换进去，跑真实 GT；
   同时用平台要求的六个材料出包，再请你用豆包工作模式跑一次盲测。
2. 换成 `核验估值日持仓数量`：公开的基金定期报告披露完整持仓与市值，
   材料可以真实获取，但只能做"估值表 ↔ 报告披露"两方核对，做不到三方。

我的判断：**优先走 1**。TCA 的判分已经能打穿，缺的只是真实数字；
而持仓核对就算换成公开材料，也拿不到券商对账单那一侧，核对的强度会下降一档。
