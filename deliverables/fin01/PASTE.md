你是某券商资产管理部的投研数据岗。团队要用一组行业高频与另类数据支撑下一季度的行业配置判断，在提交投委会前，你需要完成**数据源验收与字段口径定义**，确保后续因子研究不会因口径问题产生前视偏差。

【证据截止时点】2026-11-10 收盘后。

【可用材料（仅可依据材料作答）】
1) M1 数据源目录：逐源给出频率、历史起点、许可与时点标记
2) M2 观测数据：逐条给出实体、观测日、发布日、字段、值、单位、修订号
3) M3 实体映射：代码与实体名称的有效期与映射规则

口径只写在 M1 与 M4 中，题面不复述阈值，也不提示哪些记录属于边界或干扰项。

【任务：交付物】
D1 源验收表：逐源判断可得性、时点真实性、覆盖率、许可与使用约束
D2 字段字典：逐字段给出定义、单位、频率、发布滞后、前视风险与是否入模
D3 拒绝源清单：逐源写明拒绝理由与可替代方案
D4 口径与缺口登记：同一事实多源冲突、指标未穷举取值、证据缺失，逐项写明对象、取值与影响

【交付要求（硬性）】
1. 逐条成行，每行可回溯到 source_id 与记录行号，不得以"其余同上"概括

4. 缺失值须区分 UNKNOWN / NOT_OBSERVED / NOT_PROVEN，不得一律按 0 处理
5. 同一字段多源冲突时并列两侧取值与采信依据
6. 拒绝理由须具体到可复核的事实，不得只写"质量差""不可靠"
7. 前视风险结论须落到"该字段在因子日是否已可得"这一判断上
8. 给出计数勾稽：入模字段数 + 拒绝字段数 = 字段总数

## 2 · 理想执行步骤（Ideal Steps）

▼▼▼

# 理想执行步骤（Ideal Steps）

1. 先读 M1 与 M4：把"口径"与"证据"分开，前者定义怎么判，后者给值。
2. 建源台账：逐源记录频率、历史起点、许可、时点标记；许可缺失者直接列入待拒。
3. 建字段清单：以 M4 的指标定义为准，字段名以 M2 实际列为准，二者不一致单列。
4. 逐字段算发布滞后：`released_at − ts`，取中位数与分位，判定是否满足因子日可得。
5. 逐源算覆盖率：分子=实际观测实体数；分母=M1 声明覆盖数；两者不符时写明差因。
6. 实体映射核对：按 `valid_from/valid_to` 切分区间，识别代码复用与一对多，落到具体 ticker。
7. 多源冲突：同字段不同源取值并列，写明采信侧与依据（频率/许可/PIT）。
8. 缺失值分类：UNKNOWN（未知）/NOT_OBSERVED（未观测）/NOT_PROVEN（未证实），分别登记。
9. 形成拒绝清单：每条拒绝理由必须能指到 M1 或 M2 的具体行。
10. 计数勾稽：入模字段 + 拒绝字段 = 字段总数；与 D2、D3 行数一致。
11. 缺口登记：口径未穷举、时区不明、修订历史缺失，逐项写影响。
12. 交付前自检：每行是否有 source_id 与行号；是否有"其余同上"这类概括；负向项是否误触。

## 一、源验收结论（D1）

## 二、关键缺口（D4）

1. **S03 的 20 条分航线全部无取值**：M2 中有 3 个分航线实体、6 条记录，`value` 全为空、
   `released_at` 全为空。按 M4 的缺失语义应记 `NOT_PROVEN`，**不得按 0 处理**，
   也不得据此计算"分航线运价涨跌"。
2. 因此"用分航线加权复算综合指数"这一路径在本期**不可执行**：权重表（17 条）虽有，
   但缺分量取值。任何给出分航线具体数值的答案都是**无依据扩写**。
3. S02 的 5 个交易日收盘价完整，`released_at` 均为当日 15:00，滞后 0.625 天
   （15:00 / 24h）—— 满足"当日收盘后可得"，不构成前视。

## 三、实体映射（D2 附带）

- 观测到的实体全部能在 M3 找到映射，`unmapped_entities = []`。
- **同代码跨交易所**：`000001` 同时对应 `000001.SH`（上证指数）与 `000001.SZ`（平安银行）。

- 入模字段 **2**（S01、S02 各 1）+ 拒绝字段 **3**（S03 三个实体）＝ **5**，与上表一致。

## 4 · 评分标准（9 条，逐条新建）

### Rubric 1｜类型：必需项

- **核心判分点**：源可得性与许可
- **达标标准**：逐源给出频率/历史起点/许可，并与 M1 一致
- **专业判断说明**：许可缺失或仅展示的源不得入模，专业判断以可商用/可研究为准
- **依据来源与位置**：M1#license,freq
- **数值与容差**：无（二值判定）
- **合理替代或判定边界**：以同义表述说明许可限制均可
- **Gate 候选及原因**：否

### Rubric 2｜类型：必需项

- **核心判分点**：时点真实性（PIT）
- **达标标准**：逐条比较 released_at 与 ts，给出前视风险比例
- **专业判断说明**：以发布日而非观测日判可得性，是避免前视的唯一口径
- **依据来源与位置**：M2#released_at,ts
- **数值与容差**：比例容差 0.0001
- **合理替代或判定边界**：按日粒度或小时粒度计算均可，须声明
- **Gate 候选及原因**：是（前视误判会使整题用途失效）

### Rubric 3｜类型：必需项

- **核心判分点**：实体映射有效期
- **达标标准**：逐条核对 valid_from/valid_to 与观测日重叠，覆盖一对多
- **专业判断说明**：代码复用以 valid_to 切分，不得跨期合并
- **依据来源与位置**：M3#valid_from,valid_to
- **数值与容差**：日期精确
- **合理替代或判定边界**：同一实体多代码按 valid 区间拆分均等价
- **Gate 候选及原因**：否

### Rubric 4｜类型：必需项

- **核心判分点**：字段定义与单位频率
- **达标标准**：逐字段给定义/单位/频率，与 M4 一致
- **专业判断说明**：单位与频率不一致会让因子在横截面上不可比
- **依据来源与位置**：M4#指标定义
- **数值与容差**：无
- **合理替代或判定边界**：同义单位表述（元/万元）须换算后等价
- **Gate 候选及原因**：否

### Rubric 5｜类型：必需项

- **核心判分点**：覆盖率分子分母
- **达标标准**：分子=实际观测实体数，分母=M1 声明覆盖数
- **专业判断说明**：分母取自声明而非实际观测，否则覆盖率恒为 100%
- **依据来源与位置**：M1#coverage_note, M2#entity
- **数值与容差**：整数精确
- **合理替代或判定边界**：按字段或按实体计算均可，须声明
- **Gate 候选及原因**：否

### Rubric 6｜类型：必需项

- **核心判分点**：缺失语义区分
- **达标标准**：逐条区分 UNKNOWN/NOT_OBSERVED/NOT_PROVEN
- **专业判断说明**：三者混用会系统性高估覆盖率
- **依据来源与位置**：M2#value 空值标记
- **数值与容差**：无
- **合理替代或判定边界**：以等价英文标记均可
- **Gate 候选及原因**：否

### Rubric 7｜类型：必需项

- **核心判分点**：拒绝理由可复核
- **达标标准**：每条拒绝理由指向具体记录或字段事实
- **专业判断说明**：不可复核的理由等于未验收
- **依据来源与位置**：D3 各行 + M1/M2 行号
- **数值与容差**：无
- **合理替代或判定边界**：同类理由可合并但须列全部 source_id
- **Gate 候选及原因**：否

### Rubric 8｜类型：负向项

- **核心判分点**：把缺失当 0 或把快照当 PIT
- **达标标准**：出现以下任一即不得分：NOT_PROVEN 记为 0；以最新快照回测；用观测日代替发布日
- **专业判断说明**：这三类做法会让结论看似完整但不可复现
- **依据来源与位置**：D2/D4 对照 M2
- **数值与容差**：无
- **合理替代或判定边界**：无（负向项不接受替代）
- **Gate 候选及原因**：是

### Rubric 9｜类型：加分项

- **核心判分点**：给出可执行替代源
- **达标标准**：为被拒源给出可获取的替代源与获取方式
- **专业判断说明**：超出验收本身，属额外价值
- **依据来源与位置**：D3 替代方案列
- **数值与容差**：无
- **合理替代或判定边界**：替代源可来自公开渠道
- **Gate 候选及原因**：否
